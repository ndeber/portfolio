# Recompiler la version du 15 octobre 2026

La version de référence est le tag **`fork-2026-10-15`**. Elle comprend les opérations PE, les engagements, les expositions DBi et devises, la sensibilité aux taux, la fiscalité des positions et des enveloppes, les widgets de frais des supports et leurs derniers ajustements d’affichage.

Sur un **Mac Apple Silicon**, avec Git et Python 3 :

```sh
git clone --branch fork-2026-10-15 --single-branch https://github.com/ndeber/portfolio.git portfolio-fork
cd portfolio-fork
python3 tools/fork/rebuild-macos.py --output ../PortfolioPerformance-recompile
```

Le script télécharge depuis la release GitHub l’environnement archivé, contrôle son SHA-256, puis utilise exclusivement ce JDK 21, Maven 3.9.11 et le cache de dépendances conservé. La compilation Maven s’effectue hors réseau. Aucune ancienne installation locale du fork, de Java ou de Maven n’est nécessaire.

Les 5 350 fichiers de la version compilée sont contrôlés par leurs empreintes. Deux fichiers de configuration du dépôt ont ensuite été complétés pour ignorer l’environnement local et conserver exactement les fins de ligne d’un fichier de test. Les empreintes de ces deux versions sont également vérifiées.

Le script exécute les 177 tests de calcul et d’interface de la sélection de régression, les six tests de préparation du paquet, puis vérifie le chargement du programme avec son Java embarqué, la lecture PDF, les engagements, l’inflation, la signature locale et l’intégrité de l’archive. Les journaux et le rapport `Validation/Rebuild.json` accompagnent la livraison produite.

L’environnement contient uniquement les outils de compilation, les dépendances et la configuration publique du fournisseur de cours, validée par l’empreinte attendue par le code amont. Il ne contient ni portefeuille personnel, ni identifiant de connexion, ni jeton de session. Les exemples présents dans le dépôt sont des démonstrations.

Pour conserver aussi la reconstruction sans accès futur à GitHub, télécharger l’archive de sources du tag et l’asset **`build-environment-macos-arm64.tar.gz`** depuis la release. Après extraction des sources :

```sh
python3 tools/fork/rebuild-macos.py \
  --environment-archive /chemin/build-environment-macos-arm64.tar.gz \
  --output ../PortfolioPerformance-recompile
```

L’application prête à l’emploi, **`PortfolioPerformancePE-mac-arm64.zip`**, est également conservée dans cette même release. La reconstruction conserve le numéro de version des bundles ; les signatures et les archives générées peuvent avoir des empreintes différentes de la livraison initiale.
